# 网页小游戏合集

个人制作的网页小游戏，欢迎下载试玩。

## 下载和游玩

1. 点击绿色 **Code → Download ZIP** 下载合集。
2. 解压压缩包，进入想玩的游戏文件夹。
3. 双击其中的 HTML 文件；方块世界请打开 index.html，并保留旁边的 css、js 文件夹。

**成功标志：浏览器显示游戏画面，可以开始操作。**

[直接下载全部游戏](https://github.com/460018273-rgb/mini-games/archive/refs/heads/main.zip)
